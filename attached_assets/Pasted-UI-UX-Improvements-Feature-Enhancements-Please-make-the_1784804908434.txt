UI/UX Improvements & Feature Enhancements

Please make the following changes without changing the existing theme, branding, or color palette. Keep the current design language and only improve the UI, UX, responsiveness, and functionality.

Global Changes
Header
Add 100px bottom margin below the header on every page so the page content never overlaps the gradient header.
Reduce the overall height of the header to make it more compact.
Remove the 👋 (wave) icon from the header.
Improve spacing and alignment to create a cleaner and more modern appearance.
Home Page
Requirement 1: Face Authentication for Punch In/Out

When the user clicks the Punch In or Punch Out button:

Display the same Face Authentication popup used during the first login.
Ask the user to verify their face before continuing.
After successful face verification, continue with the Punch In or Punch Out process.
If verification fails, do not allow punching.
Requirement 2: Quick Actions Navigation

When the user clicks any card inside the Quick Actions section:

Redirect the user to the Attendance page.
The corresponding popup or action should open automatically after navigation if applicable.

Final Notes
Do not change the application's existing theme or branding.
Maintain the same color palette and overall design language.
